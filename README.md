# ☕ BrewLab Coffee Shop Management System

A modern Android-based Coffee Shop Management System that streamlines coffee ordering, inventory management, customer engagement, and delivery operations. The application is designed with three user roles: **Admin**, **Customer**, and **Delivery Person**.


# 📱 System Modules

## 👨‍💼 Admin Module

The Admin Dashboard provides complete control over the coffee shop.

### Features

- 🔐 Secure Admin Login
- 📊 Dashboard Overview
- 📦 Manage Products
  - Add Products
  - Update Products
  - Delete Products
- 🏷️ Manage Categories
- 📋 Manage Customer Orders
- 👥 View Customers
- 📦 Manage Inventory
- ⚠️ Low Stock Alerts
- 🚚 Assign Delivery Personnel
- 🔄 Update Order Status
- 💳 View Payments
- 📈 Generate Business Reports
- ⭐ View Customer Feedback
- 🎁 Manage Loyalty Program
- 🔍 Search Products & Orders
- 🚪 Logout


## 👤 Customer Module

Customers can browse, order, and track coffee directly from the mobile application.

### Features

- 📝 Register Account
- 🔐 Login
- 👤 Manage Profile
- ☕ Browse Coffee Menu
- 🔍 Search Products
- ❤️ Coffee Customization
- 🛒 Shopping Cart
- ➕ Add Items to Cart
- ✏️ Update Cart
- ❌ Remove Cart Items
- 💳 Place Orders & Online Payment
- ⏳ Brew Time Tracking
- 🚚 Delivery Tracking
- 📦 Track Orders
- 📜 Order History
- 🔄 Quick Reorder
- 🎁 Loyalty Points
- ⭐ Submit Ratings & Feedback
- 🚪 Logout


## 🚚 Delivery Person Module

Delivery personnel manage assigned deliveries efficiently.

### Features

- 🔐 Delivery Login
- 📦 View Assigned Orders
- ✅ Accept Delivery Requests
- 📍 View Customer Location
- 🗺️ Google Maps Navigation
- 🚚 Update Delivery Status
- ✔️ Mark Orders as Delivered
- 📜 View Delivery History
- 🚪 Logout
